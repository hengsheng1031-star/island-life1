小島生活 v0.2｜Vercel 靜態網頁專案

1. 本專案包含 index.html、assets/island-scene.webp、vercel.json。
2. 最簡單部署：建立 GitHub 儲存庫，將這三項上傳至儲存庫根目錄。
3. 在 Vercel 點 Add New → Project → Import Git Repository，選擇該儲存庫。
4. Framework Preset 選 Other；Build Command 留空；Output Directory 留空或預設；按 Deploy。
5. 這是公開測試版，資料存在各玩家的瀏覽器 localStorage，不支援帳號、跨裝置同步或好友功能。
6. 本版使用已確認風格的場景插畫作背景，農田與魚塘仍為可點擊的操作介面；自由佈置暫時在獨立格子頁面。
7. 作物成長為加速測試數值。正式多人版需要後端驗證與雲端資料庫。
